#### 🛠️ Things I'm building

- **Social media footprint analyzer**: I save a lot of posts and reels and almost never look at them again. So I grabbed my Instagram and Facebook data exports, added a bit of context to every save and grouped them by topic. Now I finally know what I've been hoarding 😅 It all stays on my own machine.
- **Short-form video to Notion** *(WIP)*: That analysis led me here. A lot of what I'd hoarded was food reels for places I never went to. Now I send the link to a bot, which works out the restaurant, looks it up and files it in Notion. I can then ask it things like *"antojo de café en Satélite"*. It has about 24 ADRs, which is a lot for a restaurant list.
- **Video editor** *(WIP)*: I give an agent my footage and an idea, and it hands back rough cuts, a Final Cut timeline and notes on why it cut what it cut. I still make the final call.
- **Photo culling** *(WIP)*: Can a script cull my photos the way I do? For running shoots it's a decent first pass. For weddings, not even close yet 🙃
- **Smart-bulb controller** *(WIP)*: I bought cheap Bluetooth mesh bulbs and didn't like their app, so I'm reverse-engineering the protocol.
- **Coding agent skills**: The ones I use every day. There are probably too many, including one that mines my old sessions for new skills.
- **Market data experiment** *(WIP)*: Looking for unusual patterns in public trading data.
